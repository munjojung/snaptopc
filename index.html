이 페이지는 PWA(Progressive Web App)를 지원합니다. 홈 화면에 추가하면 일반 앱처럼 전체 화면으로 빠르게 실행할 수 있습니다.

  • • 안드로이드 (Chrome): 우측 상단 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치
  • • 아이폰 (Safari): 하단 공유 버튼(□↑) → 홈 화면에 추가
  • • 노트북 (Chrome/Edge): 주소창 우측 설치 아이콘 클릭
